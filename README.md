# Wox Todo Plugin

本地待办事项管理插件，数据完全存储在本地，无需网络服务。

## 功能特性

- ✅ **快速添加**：输入 `todo 任务内容` 即可添加待办事项
- ✅ **智能搜索**：输入 `todo 关键词` 快速查找相关任务
- ✅ **状态管理**：一键标记任务完成/删除任务
- ✅ **分类展示**：待完成任务在前，已完成任务在后
- ✅ **过期清理可配置**：插件设置中可调整已完成任务的自动清理天数（输入 0 表示永不清除，上限 365 天）
- ✅ **操作后保持窗口**：插件设置中可开启「操作后保持窗口显示」（默认开启），添加/标记完成/删除后窗口不隐藏，便于连续操作列表，此时按上方向键可在列表内循环导航（不被查询历史回退抢走）；关闭则操作后自动隐藏窗口
- ✅ **本地存储**：数据存储在 `~/.wox/data/todo.json`，完全离线可用
